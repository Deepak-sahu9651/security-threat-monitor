# Contributing Guide

## Getting Started

1. Fork the repository
2. Clone your fork
3. Create a feature branch
4. Make changes
5. Submit a pull request

## Code Style

### Python
- Follow PEP 8
- Use type hints
- Add docstrings

### JavaScript
- Use ES6+
- Follow Airbnb style guide
- Add PropTypes

## Commit Messages

```
[feature|fix|docs|style|refactor|test]: Brief description

Detailed explanation if needed
```

## Testing

Add tests for new features:

```bash
# Backend
python -m pytest

# Frontend
npm test
```

## Pull Request Process

1. Update documentation
2. Add/update tests
3. Follow code style
4. Provide clear PR description
5. Link related issues
